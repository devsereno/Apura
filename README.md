# Apura

Painel de resultados da eleição brasileira (Espírito Santo 2026) com colinha pessoal.

## Recursos
- Tela inicial com escolha de modo **TV** ou **Celular**
- Tema claro e escuro
- Logo Apura (claro e escuro)
- Ranking de mais votados melhorado
- Colinha de candidatos (salva no navegador)
- Atualização automática dos dados do TSE

## Como usar
1. Coloque os arquivos na pasta do repositório GitHub Pages
2. Acesse `index.html`
3. Escolha o modo de visualização
